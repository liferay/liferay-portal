Anonymous user id shared across subdomains

Reach this page through two hostnames that share one parent domain, so the browser can be seen sharing the ac_client_user_id cookie between them.

Two servers are needed. yarn start serves the bundle alone on port 8081, so this page needs a static server of its own, from the module root: 

yarn start # bundle at localhost:8081
python3 -m http.server 8000 # this page, from the module root

Then open the page through two names under test.localhost: 

http://a.test.localhost:8000/test/manual/cookie-domain.html
http://b.test.localhost:8000/test/manual/cookie-domain.html

Nothing else is needed. The browser resolves every *.localhost name to the loopback address itself, so there is no /etc/hosts entry to add and no domain owned by anyone else to depend on. It also treats those names as a secure context, which matters because the client marks the cookie Secure and a browser stores such a cookie only from an origin it trusts — over plain HTTP any other hostname would need --unsafely-treat-insecure-origin-as-secure for the cookie to land at all.
