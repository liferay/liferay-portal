# Checks for .expect, .sh, or .tpl

Check | Category | Description
----- | -------- | -----------

SHSubshellCheck | [Bug Prevention](bug_prevention_checks.md#bug-prevention-checks) | Checks that local variables are not assigned via subshells. |
WhitespaceCheck | [Styling](styling_checks.md#styling-checks) | Finds missing and unnecessary whitespace. |
