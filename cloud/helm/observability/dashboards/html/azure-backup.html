Restoring From a Recovery Point

On Azure, restores run through the backup-restore workflow template in the environment namespace. It takes the recovery point ID listed above as its only argument.

🟢
1. Pick a Succeeded Backup
Use a SUCCEEDED row from the active data plane. The workflow rejects recovery points from the inactive data plane and points older than the active database's restore window.
📋
2. Copy the Recovery Point ID
Hover the ID cell, select the inspect icon, and select Copy to Clipboard.
🚀
3. Submit the Restore
argo submit \ --from workflowtemplate/backup-restore-workflow-template \ --namespace ${environment} \ --parameter recovery-point-id=<ID>
or
Argo Workflows
Set centralHub.argoWorkflowsURL in your values.yaml to enable this link.
Azure Resource Graph only keeps the last 14 days of backup jobs, so recovery points older than that are not listed even if they have not expired. List them with az dataprotection recovery-point list against the backup instance of the active data plane.
